# nintendogs

A fan-made, from-scratch recreation of the Nintendo DS Nintendogs (2005) feel: a 3D puppy you pet, wash, walk, and name, with the DS-era soft-lit look.

No original Nintendo assets or code are used. Everything here is built new.

Planning. One-week design sprint scoped in `docs/SPRINT_PLAN.md`.

## Research (2026-09-14)

Searched GitHub (repo search, Swift filter), Google, X/Nitter, Bing, DuckDuckGo for an existing Swift/iOS recreation with matching 3D graphics. None found. Closest hits are a 3DS save editor, a Java virtual-pet toy, a browser 2D clone, and a Unity VR project. This project fills that gap.
